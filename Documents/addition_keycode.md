# GBC24 追加キーコード一覧
 
GBC24で使用できる独自キーコードの一覧です。  
RemapまたはVIAでキーに割り当ててご使用ください。
 
## ジョイスティック
 
| キーコード | 説明 |
|------------|------|
| `JOY_DIGI` | ジョイスティックをデジタル4方向入力に切り替え |
| `JOY_MOUS` | ジョイスティックをマウス入力に切り替え |
| `JOY_ANLG` | ジョイスティックをアナログ軸入力【DirectInput】に切り替え |
| `JOY_SPD_UP` | マウス最大速度を上げる[^2] |
| `JOY_SPD_DN` | マウス最大速度を下げる[^2] |
| `JOY_DZ_UP` | 現在のモードのデッドゾーンを広げる（鈍くする）[^2] |
| `JOY_DZ_DN` | 現在のモードのデッドゾーンを狭める（敏感にする）[^2] |
| `JOY_DZ_RST` | 3モードすべてのデッドゾーンを既定値に戻す[^2] |

ジョイスティックの入力モード（デジタル／マウス／アナログ）は保存されません。電源を入れるたびにデジタル4方向モードから始まります。
 
### デッドゾーンの調整
 
`JOY_DZ_UP` / `JOY_DZ_DN` は、**その時アクティブなモード**のデッドゾーンを1回あたり2%ずつ変更します。  
調整したいモードに `JOY_DIGI` / `JOY_MOUS` / `JOY_ANLG` で切り替えてから操作してください。  
 
| モード | 調整範囲 | 初期値 | 段階数 |
|--------|----------|--------|--------|
| デジタル | 6〜90% | 54% | 43段階 |
| マウス | 4〜90% | 24% | 44段階 |
| アナログ | 2〜90% | 12% | 45段階 |
 
デジタルモードのセンター判定しきい値は、方向判定しきい値に連動して自動調整されます。
 
## トラックボール
 
以下のキーコードは、オプションのReexトラックボールユニットを取り付けた場合にご利用いただけます。
 
### 設定の保存・リセット
 
| キーコード | 説明 |
|------------|------|
| `REC_RST` | センサー設定[^1]を初期値に戻す（保存はしない） |
| `REC_SAVE` | 現在のセンサー設定[^1]をEEPROMに保存 |

トラックボールの設定は、`REC_SAVE` を押したときだけEEPROMに保存されます（自動保存はありません）。  
`REC_SAVE` を押さずに電源を切ると、最後に `REC_SAVE` した値に戻ります。  
保存済みかどうかは `CFG_SHOW`（後述の「設定値の確認」）で確認できます。

| 設定 | `REC_SAVE` で保存 | 初期値 |
|------|:----:|------|
| CPI | ○ | 500 |
| スクロール除数 | ○ | 4（1/8） |
| スクロールスナップ | ○ | 垂直 |
| 自動マウスレイヤーのON/OFF | ○ | OFF |
| 自動マウスレイヤーのタイムアウト | ○ | 650ms |
| スクロールモードのON/OFF | ×（電源を入れると常にOFF） | OFF |

`REC_RST` を押しても、スクロールスナップは初期値に戻りません。  
初期値に戻した状態を残したい場合は、`REC_RST` のあとに `REC_SAVE` を押してください。
 
### CPI（カーソル速度）
 
| キーコード | 説明 |
|------------|------|
| `CPI_I100` | CPIを100増加（最大3500） |
| `CPI_D100` | CPIを100減少（最小100） |
| `CPI_I1K` | CPIを1000増加（最大3500） |
| `CPI_D1K` | CPIを1000減少（最小100） |
 
### スクロール
 
| キーコード | 説明 |
|------------|------|
| `SCRL_TO` | 押すたびにスクロールモードのON/OFFを切り替え |
| `SCRL_MO` | 押している間だけスクロールモード |
| `SCRL_DVI` | スクロール除数を1つ上げる（最大 7 = 1/64、最も遅い） |
| `SCRL_DVD` | スクロール除数を1つ下げる（最小 1 = 1/1、最も速い） |
| `SSNP_VRT` | スクロールスナップを垂直方向に固定 |
| `SSNP_HOR` | スクロールスナップを水平方向に固定 |
| `SSNP_FRE` | スクロールスナップを無効化（自由スクロール） |
 
### 自動マウスレイヤー
 
| キーコード | 説明 |
|------------|------|
| `AML_TO` | 自動マウスレイヤーのON/OFFを切り替え |
| `AML_I50` | 自動マウスレイヤーのタイムアウトを50ms増加（最大1000ms） |
| `AML_D50` | 自動マウスレイヤーのタイムアウトを50ms減少（最小100ms） |

#### 動作

自動マウスレイヤーのONの状態で、トラックボールを転がすと**レイヤー3**に自動で切り替わり、操作をやめてから設定時間（初期値650ms）が経過すると元のレイヤーに戻ります。  
レイヤー3にマウスボタンやスクロールを割り当てておくことで、レイヤー切り替えキーを押さずにマウス操作ができます。  

レイヤー3では、以下のキーがトラックボールを止めた状態でもレイヤーを維持します。  
マウス操作を続けるためのキーとして扱われるためです。  

- マウスボタン（`KC_BTN1`〜`KC_BTN8`）
- `SCRL_MO`
- 修飾キー（Ctrl / Shift / Alt / GUI）

上記以外のキーを割り当てた場合、押した時点でレイヤー3が解除され、下のレイヤーのキーが入力されます（トラックボールを動かしながら押した場合はレイヤー3のキーが入力されます）。  
そのため、レイヤー3には上記のキーを割り当てることを推奨します。  

なお、キーを押した直後の約200msはトラックボールを動かしてもレイヤーが切り替わりません。  
タイピング中に手が触れてしまった際の誤動作を防ぐための仕様です。  

## 設定値の確認

OLEDを装着していなくても、現在の設定値を確認できます。

| キーコード | 説明 |
|------------|------|
| `CFG_SHOW` | 現在の設定値をテキストとして入力する |

メモ帳などのテキストエディターを開き、日本語入力（IME）をOFFにしてから `CFG_SHOW` を押してください。  
設定値が1項目1行で入力されます。

### 出力例

ジョイスティック使用時:

```
GBC24 joystick
mode            mouse
mouse speed     15 / 50
deadzone digi   54%
deadzone mouse  24%   <- current
deadzone analog 12%
eeprom          saved
```

トラックボール使用時:

```
GBC24 trackball
cpi             500
scroll mode     off
scroll div      4  1/8
scroll snap     vertical
auto mouse      on
aml timeout     650ms
eeprom          saved
```

### 各項目の意味

| 項目 | 意味 | 表示される値 |
|------|------|------|
| `mode` | ジョイスティックの入力モード | `digi`（デジタル4方向）／ `mouse`（マウス）／ `analog`（アナログ軸） |
| `mouse speed` | マウス最大速度（現在値 / 上限） | `1`〜`50` / `50` |
| `deadzone digi` | デジタルモードのデッドゾーン | `6%`〜`90%` |
| `deadzone mouse` | マウスモードのデッドゾーン | `4%`〜`90%` |
| `deadzone analog` | アナログモードのデッドゾーン | `2%`〜`90%` |
| `<- current` | 現在のモードのデッドゾーンに付く印 | ― |
| `eeprom`（ジョイスティック） | 保存状態 | `saved`（保存済み）／ `auto saving`（変更直後で、約2秒後に自動保存される） |
| `cpi` | トラックボールのCPI | `100`〜`3500`（センサーが検出できない場合は `none`） |
| `scroll mode` | スクロールモード | `on` ／ `off` |
| `scroll div` | スクロール除数とその倍率 | `1  1/1`〜`7  1/64` |
| `scroll snap` | スクロールスナップ | `vertical`（垂直）／ `horizontal`（水平）／ `free`（無効） |
| `auto mouse` | 自動マウスレイヤー | `on` ／ `off` |
| `aml timeout` | 自動マウスレイヤーのタイムアウト | `100ms`〜`1000ms` |
| `eeprom`（トラックボール） | 保存状態 | `saved`（保存済み）／ `not saved, press REC SAVE`（未保存。`REC_SAVE` を押さないと電源OFFで元に戻る） |

### 注意

- 1項目ごとにEnterキーを送って改行します。チャット欄やコマンドプロンプトで押すと、送信や実行が行われてしまうのでご注意ください。
- 日本語入力がONのままだと、かなに変換されて入力されます。
- 出力には、US配列・JIS配列のどちらのPCでも同じ文字になる記号だけを使用しています。
- 自動マウスレイヤー（レイヤー3）で押すと、ほかの通常キーと同じくレイヤー3が解除されます。
 
[^1]: CPI、スクロール除数、スクロールスナップ、自動マウスレイヤーのON/OFF状態、および自動マウスレイヤーのタイムアウト
 
[^2]: マウス最大速度とデッドゾーンは、変更から約2秒後に自動でEEPROMへ保存されます。トラックボールの `REC_SAVE` のような保存操作は不要
